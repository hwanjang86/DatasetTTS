스크립트 파일명이 ElevenLabs 보이스 이름입니다. 프로젝트 폴더에 .txt를 넣으면 여기 나타납니다.

숫자를 한글로 펼치고 조사를 교정합니다. 크레딧이 들지 않습니다.

단어 재작성 검토 필요

조사 교정은 단어를 고쳐 씁니다. 실제 명사가 여기 있으면 데이터가 손상됩니다 (가을 → 가를 같은 경우). 보호 목록에 넣으세요.

비용 확인

생성

이미 생성된 클립은 건너뜁니다. 중단해도 이어서 진행할 수 있습니다.

재생성

테이크 번호가 seed를 바꿉니다. 같은 번호는 같은 오디오를 냅니다.

retrim — 앞뒤 무음 정리

저장된 클립의 앞뒤 무음을 일정하게 맞춥니다. 생성 시 적용이 빠진 클립을 찾아 수리합니다. 멱등성이 있어 반복 실행해도 안전합니다.

declick — 끝부분 잡음 제거

발화 뒤에 붙은 짧은 틱을 각 클립의 발화 끝 지점에서 잘라냅니다. 고정 길이가 아니라 클립마다 다르게 자릅니다. 원본은 output/<보이스>/originals/에 백업되며 Review 탭에서 되돌릴 수 있습니다.

실행 후 Review 탭에서 반드시 들어보세요. 마지막 음절이 짧고 급하게 끝나는 클립은 발화가 잘못 잘릴 수 있습니다.
