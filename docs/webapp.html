실행하기

ElevenLabs SDK가 설치된 venv의 파이썬으로 실행합니다. 시스템 파이썬으로는 동작하지 않습니다.

1. 프로젝트 폴더로 이동

cd E:\AI\DatasetTTS

2. 서버 시작

PowerShell에서:

& "$env:USERPROFILE\.claude\mcp-servers\elevenlabs\venv\Scripts\python.exe" -m webapp

이 긴 경로가 venv의 파이썬입니다. 매번 치기 번거로우면 변수에 담아 두세요.

$PY = "$env:USERPROFILE\.claude\mcp-servers\elevenlabs\venv\Scripts\python.exe"
& $PY -m webapp

3. 이 출력이 나오면 성공

API key   : found
DatasetTTS: http://127.0.0.1:8765
stop with : Ctrl+C

브라우저에서 http://127.0.0.1:8765 를 엽니다. API key : MISSING이 뜨면 환경변수가 설정되지 않은 것입니다 — 둘러보기와 오디오 도구는 되지만 생성·재생성은 실패합니다.

4. 종료

실행한 터미널에서 Ctrl+C. 터미널을 그냥 닫으면 프로세스가 남아 포트를 붙잡고 있을 수 있습니다.

자주 하는 작업

클릭 순서 그대로.

새 보이스를 처음 돌리기

  1. ElevenLabs 보이스 이름과 똑같은 .txt를 프로젝트 폴더에 넣고 새로고침
  2. Scripts — 카드가 보이고 파싱 오류가 없는지 확인
  3. Preview — 정규화 실행 → 단어 재작성 표를 한 줄씩 읽기. 오탐이 있으면 보호 목록에 추가하고 서버 재시작 후 다시 실행
  4. Preview — 줄 단위 확인에서 "변경된 줄만" 켜고 몇 페이지 훑기
  5. Generate — 줄 수 제한에 50 → 예상 비용 계산 → 생성 시작
  6. Review — 50건 들어보기. 톤·숫자 발음·감정 확인
  7. 문제없으면 Generate에서 줄 수 제한을 비우고 생성 시작
  8. Tools — 검사만으로 retrim → declick 순서로 확인 후 실행
  9. Review — 필터를 "잡음 제거된 것만"으로 놓고 결과 검수

QC 플래그가 뜬 클립 처리하기

  1. Review — 필터 "QC 플래그만" → 불러오기
  2. 몇 개를 재생해서 실제로 문제가 있는지 확인
  3. 끝의 짧은 틱이면 → Tools의 declick (무료)
  4. 발음이나 톤 자체가 이상하면 → Generate의 재생성 (유료)
  5. 재생성했는데 똑같으면 테이크를 2로 올려 다시

같은 문제라도 원인에 따라 대응이 다릅니다. 틱은 잘라내면 되고, 톤은 다시 만들어야 합니다.

잘못 잘린 클립 되돌리기

  1. Review — 필터 "잡음 제거된 것만"
  2. 해당 클립의 파형을 눌러 현재와 원본을 나란히 확인
  3. 원본 재생으로 잘리기 전 소리 확인
  4. 원본으로 되돌리기

여러 개가 잘못 잘렸다면 잘라내기 임계값이 이 보이스에 안 맞는 것입니다. audio.py의 ARTIFACT_MAX_MS를 낮추고 다시 시도하세요.

중단했다가 이어서 하기

  1. 작업 바에서 중단
  2. 나중에 Generate에서 생성 시작을 다시 누르기

이미 만든 클립은 자동으로 건너뜁니다. 중복 과금이 없습니다. "기존 파일도 다시 생성"은 켜지 마세요 — 켜면 처음부터 다시 청구됩니다.

알아둘 동작

상황어떻게 되는가
작업 중에 다른 작업을 시작 거부됩니다. "a job is already running: …" 토스트. 한 번에 하나만 돌아갑니다
브라우저 탭을 닫음 작업은 계속됩니다. 서버에서 돌기 때문입니다. 다시 열면 현재 상태가 그대로 보입니다
작업 도중에 페이지를 열었을 때 진행률이 바로 채워집니다. 처음부터 보고 있지 않아도 됩니다
보호 목록에 단어 추가 소스 파일이 수정됩니다. 서버 재시작 후에 반영됩니다
보이스 드롭다운 변경 Preview·Review에 불러왔던 내용이 지워집니다. 다시 불러오기를 누르세요
서버를 끄고 싶을 때 실행한 터미널에서 Ctrl+C

루프백 전용입니다. 인증이 없고, 프로세스가 API 키를 들고 있으며, 버튼 한 번으로 크레딧을 쓸 수 있습니다. --host로 외부 주소에 바인딩하지 마세요.

CLI와의 관계

웹앱은 CLI와 같은 코드를 호출합니다. 정규화·QC 로직을 따로 구현하지 않았기 때문에 두 경로의 결과가 항상 같습니다. 웹앱에서 생성하다 중단하고 CLI로 이어가도 되고, 그 반대도 됩니다.
